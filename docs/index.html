How it works

Scan a Rubik's cube, solve it, and let the machine turn it.

ARS Studio is the desktop software for the ARS cube-solving machine. It also works on its own, as a solver you can follow move by move.

How it works

01

Scan

Hold the cube up to a webcam. Each face is found in the picture, read and stored without pressing anything, in whatever order you show them.

Faces
6, any order
Stickers read
54
Manual entry
keys 1 to 6
02

Solve

Pick how you want it solved: as short as possible, or the layer-by-layer way people learn first. A cube that cannot exist is explained, not just refused.

Optimized
~19 moves
Kociemba
~21 moves
Layers
~120 moves
03

Follow

Play the solution in 2D or 3D, scrub through it, or step one move at a time with the arrow keys.

D'F'U2R'UBR'D'F'LD'F2D'B2L2B2D2B2UL2U2R2
04

Run

The moves are translated into gripper commands for the ARS machine and sent over a serial port. A 3D simulation shows what it will do, and how long it will take, before anything moves.

lmkjnihjgilnkjmi
djci bb flek cjdi

The machine simulation, playing the same solution the hardware receives.

Build it yourself

The whole project is open source. You need the .NET 10 SDK and nothing else.

git clone https://github.com/xm1k3/ars-project.git
cd ars-project
dotnet run --project src/ArsStudio
